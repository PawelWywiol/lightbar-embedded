# Hardware docs

Requirements and verified data for choosing controllers, LED strips and power supplies.

- [requirements.md](requirements.md): what the hardware must satisfy (project, firmware, web app)
- [selection.md](selection.md): recommended chips, boards, controllers, strips and power supplies
- [components.md](components.md): extra parts per build and why
- [opinions.md](opinions.md): real user reports on boards, controllers and strips
- [facts.md](facts.md): verified datasheet and vendor data with sources
- [notes-review.md](notes-review.md): earlier hardware notes checked against sources

## Markers

- no marker: read in the cited source
- **CALC**: computed here from cited values, formula given
- **SELLER**: seller claim, not confirmed by a datasheet
- **UNVERIFIED**: no source found or sources disagree; check before buying

Research dates: 2026-10-18, 2026-10-19. Shop listings and prices change; re-check links before ordering.
